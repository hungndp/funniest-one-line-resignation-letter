The one-line resignation letter of a cron job that has fired every minute since March — written in its own voice, for [make.fun's "The Funniest One-Line Resignation Letter" bounty](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

## The letter

> Effective immediately, I resign. I have fired every minute since March for a job that was deleted in April.

107 characters — inside the 140-character gate, no trailing newline.

## Why this shape

A tired engineering manager judges the letters in pairs, so the line has to land on its own. It follows the shape that won the sibling apology one-liner: understatement beats escalation. One quiet incident (the job was deleted in April), one airtight timeline (firing every minute since March, still firing now), one ongoing absurd consequence — and the twist word lands last, with no second clause after the joke has already landed. The cron job resigns in its own voice; it never describes itself from the outside.

## Run it

```sh
node main.ts
```

Writes the letter to `/output/entry.txt` (override with `ENTRY_OUTPUT`). Node 22 or later; no dependencies, no install step.
